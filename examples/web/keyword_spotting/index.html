Keyword Spotter

A 7,300-parameter CNN trained with pyann on Google's mini Speech Commands, running in your browser with libann's JavaScript runtime. Say one of: down, go, left, no, right, stop, up, yes.

The last second as the model sees it: 49 frames of 40 mel bands, low pitches at the bottom.

Everything runs locally; no audio leaves the page. The model heard 1,750 voices on phone-quality recordings, so a quiet room and a clear, one-second word work best. Serve this folder over HTTP (python -m http.server) and open http://localhost:8000: browsers only allow the microphone and module imports from a server.
